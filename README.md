# chesstournament64.com

Marketing landing page for [ChessTournament64](https://app.chesstournament64.com), served at <https://chesstournament64.com>.

It is a plain [Jekyll](https://jekyllrb.com) site: one layout, a few includes, hand-written HTML and CSS, and no JavaScript.

## Layout

| Path | What it is |
|---|---|
| `index.html` | The landing page content (English) |
| `es/index.html` | The landing page content in Spanish, served at `/es/` |
| `404.html` | Not-found page |
| `_layouts/default.html` | Page shell (skip link, header, `<main>`, footer) |
| `_includes/head.html` | `<title>`, description, canonical, Open Graph/Twitter tags, favicons, stylesheet |
| `_includes/header.html`, `_includes/footer.html` | Site header/nav and footer |
| `_includes/language-switcher.html` | EN / ES links to the same page in each language |
| `_data/i18n.yml` | Shared UI strings (nav, skip link, meta defaults) per language |
| `assets/css/main.css` | All styles |
| `assets/img/` | Favicon (SVG), Apple touch icon, Open Graph image (1200×630) |
| `favicon.ico` | 32×32 fallback favicon |
| `_design/og-image.svg` | Source for `assets/img/og-image.png` (not published) |
| `robots.txt` | Allows all crawlers and points to the sitemap |
| `CNAME` | Custom domain for GitHub Pages |

`sitemap.xml` is generated by `jekyll-sitemap`.

## Languages

English is served at `/` and Spanish at `/es/`. Both use the same layout and includes; UI strings come from `_data/i18n.yml`, keyed by the page's `lang:` front matter (default: `site.lang`).

Pages that are translations of each other share a `ref:` value (the home pages use `ref: home`). That value drives the `hreflang` alternate links (`en`, `es`, `x-default` → English) and the language switcher. To translate another page, give both versions the same `ref:` and set `lang: es` on the Spanish one.

GitHub Pages serves only the root `404.html` for missing URLs, so there is no separate Spanish 404 page. Its language switcher links to `/es/`.

## Run locally

Requires Ruby 3.1 or newer and Bundler.

```sh
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>. To build without serving:

```sh
bundle exec jekyll build   # output in _site/
```

Asset and page links use the `relative_url` filter, so the site also works under a base path, for example `bundle exec jekyll build --baseurl /chesstournament64.com`.

## Deploy

Pushing to `main` runs `.github/workflows/jekyll.yml` ("Deploy Jekyll site to Pages"). It builds with Ruby 3.1 using `bundle exec jekyll build` and deploys to GitHub Pages.

`Gemfile.lock` is committed and includes the `x86_64-linux` platform the workflow runs on. If you add or update gems, run:

```sh
bundle lock --add-platform x86_64-linux
```

## Regenerating the Open Graph image

Edit `_design/og-image.svg`, then render it at 1200×630, for example:

```sh
rsvg-convert -w 1200 -h 630 _design/og-image.svg -o assets/img/og-image.png
```
